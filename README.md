# Tower of Hanoi

## Live Website

https://cyrondagami.github.io/tower-of-hanoi/

## About the Project

An interactive Tower of Hanoi game built with **HTML, CSS, and JavaScript**. It has an animated intro, four difficulty modes, hints, undo, auto-solve, a rewards system, and customizable themes.

## Features

- 4 difficulty modes: Easy, Medium, Hard, Super Hard
- Win goals: Classic, Win by Moves, Win by Time
- Hint, Undo, Restart, and Auto-solve
- Coins, XP, levels, achievements, and a daily chest
- Unlockable themes and disk styles
- Sound effects and background music
- Works on desktop and mobile

## How to Play

1. Click a tower to lift its top disk.
2. Click another tower to drop it.
3. Move the whole stack from tower A to tower C.
4. Never put a bigger disk on a smaller one.

## Keyboard Shortcuts

`1 2 3` tower · `U` undo · `R` restart · `H` hint · `A` auto · `M` sound · `N` music · `S` settings · `O` home · `P` rewards
